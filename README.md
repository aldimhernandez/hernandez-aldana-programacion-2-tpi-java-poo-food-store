# hernandez-aldana-programacion-2-tpi-java-poo-food-store
Sistema de gestión de pedidos de comida desarrollado en Java 21 para la materia Programación 2. Implementa un menú de consola con CRUD de categorías, productos, usuarios y pedidos, aplicando POO, colecciones, interfaces, herencia, enums, validaciones y manejo de excepciones.
