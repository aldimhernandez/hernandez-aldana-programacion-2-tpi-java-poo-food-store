# Food Store – Sistema de Gestión de Pedidos

Trabajo Práctico Integrador de la materia **Programación 2** de la **Tecnicatura Universitaria en Programación a Distancia** de la **Universidad Tecnológica Nacional (UTN)**.

---

# Descripción

Food Store es una aplicación de consola desarrollada en **Java 21** para gestionar categorías, productos, usuarios y pedidos de un negocio de comidas.

La aplicación almacena toda la información en memoria utilizando **colecciones**, por lo que los datos permanecen disponibles únicamente durante la ejecución del programa.

El desarrollo aplica los conceptos de Programación Orientada a Objetos (POO), incluyendo herencia, encapsulamiento, interfaces, enums, excepciones personalizadas y separación por capas.

# Funcionalidades

## Gestión de categorías

- Listar categorías
- Crear categorías
- Editar categorías
- Eliminar mediante baja lógica

## Gestión de productos

- Listar productos
- Crear productos
- Editar productos
- Eliminar mediante baja lógica

## Gestión de usuarios

- Listar usuarios
- Crear usuarios
- Editar usuarios
- Eliminar mediante baja lógica

## Gestión de pedidos

- Listar pedidos
- Crear pedidos con uno o más detalles
- Actualizar estado del pedido
- Actualizar forma de pago
- Eliminar mediante baja lógica

# Ejecución desde NetBeans

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en NetBeans.
3. Configurar Java 21 como plataforma del proyecto.
4. Ejecutar la clase:

```
src/app/Main.java
```

# Estructura del proyecto

```
src/
├── app/
│   └── Main.java
├── entities/
├── enums/
├── exceptions/
├── interfaces/
├── services/
├── ui/
└── validations/
```

### Descripción de los paquetes

| Paquete       | Descripción                               |
|---------------|-------------------------------------------|
| app           | Punto de entrada de la aplicación         |
| entities      | Modelo del dominio                        |
| enums         | Enumeraciones utilizadas por el sistema   |
| exceptions    | Excepciones personalizadas                |
| interfaces    | Interfaces del dominio                    |
| services      | Lógica de negocio                         |
| ui            | Menús e interacción por consola           |
| validations   | Validaciones reutilizables                |
